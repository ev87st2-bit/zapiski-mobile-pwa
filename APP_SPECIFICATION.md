# Спецификация: личное приложение «Заметки, идеи и задачи»

## Назначение

Минималистичное мобильное веб-приложение для одного пользователя. Оно помогает быстро сохранять заметки, идеи и задачи, а также вовремя возвращаться к важному.

## Основные сценарии

1. Пользователь открывает приложение и выбирает: «Заметка», «Идея» или «Задача».
2. Содержание вводится вручную или диктуется; голос автоматически преобразуется в текст.
3. Идея напоминает о себе через 7 дней, если пользователь к ней не вернулся.
4. Для задачи задаются дата и, при необходимости, время. В назначенный момент приходит звуковое уведомление.
5. Экран «Сегодня» показывает актуальные задачи и идеи, к которым пора вернуться.

## Экраны

### Сегодня

- задачи на текущий день;
- просроченные активные задачи;
- идеи, для которых сегодня наступило напоминание;
- быстрый переход к созданию записи.

### Создать

- три крупные кнопки: «Заметка», «Идея», «Задача».

### Редактор

- текстовое поле;
- кнопка голосового ввода;
- сохранение;
- редактирование и удаление записи.

### Календарь

- интерактивный календарь;
- текущий день заметно выделен;
- выбор даты;
- выбор времени для задачи.

### Все записи

- общий список заметок, идей и задач;
- разделение по типу и статусу.

### Детали записи

- полный текст;
- дата создания;
- информация о напоминании;
- «Изменить» и «Удалить»;
- для задач — отметка «Выполнено».

## Поведение сущностей

- **Заметка:** сохраняется с датой создания, без обязательного напоминания.
- **Идея:** получает автоматическое напоминание через 7 дней.
- **Задача:** имеет дату и опциональное время; при наличии времени создаётся звуковое уведомление.
- **Выполненная задача:** скрывается из активного списка, но сохраняется в истории.
- **Удаление:** требует короткого подтверждения.
- **Голосовой ввод:** распознаётся и превращается в текст; аудиозапись отдельно не хранится.

## Данные и ограничения

- приложение используется на одном телефоне;
- данные хранятся локально;
- нет аккаунта, синхронизации и резервных копий;
- часовой пояс берётся с телефона;
- при отсутствии разрешений на микрофон или уведомления приложение объясняет, как их включить.

## Дизайн

- интерфейс прежде всего для телефона;
- белый фон;
- синие акцентные кнопки и элементы управления;
- крупные зоны нажатия;
- много свободного пространства;
- минимум шагов для создания записи.

## Техническое направление

- мобильное веб-приложение, устанавливаемое как PWA;
- локальное хранилище браузера;
- распознавание речи через доступный браузерный API или механизм устройства;
- системные уведомления со звуком для задач;
- адаптация под iPhone и Android с учётом ограничений браузерных уведомлений.
