# Записки

Мобильное PWA для заметок, идей, задач и личного планирования. Базовые записи работают локально на устройстве. Telegram, Google Calendar и AI подключаются отдельно и только по решению пользователя.

## Что уже реализовано

- заметки, идеи с возвратом через 7 дней, задачи, календарь и история выполнения;
- локальный голосовой ввод браузера без хранения аудио;
- личные и рабочие цели с недельными этапами, предлагаемыми датами и редактированием до подтверждения;
- ежегодные дни рождения и строки «Сегодня/Завтра»;
- Google OAuth и синхронизация только событий, которыми управляет приложение;
- Telegram-бот как единый канал сообщений для задач, встреч, событий и дней рождения;
- одна общая ссылка и один бот для нескольких родственников с отдельными личными данными и календарями;
- голосовые сообщения Telegram: временное скачивание, расшифровка, проект задач и подтверждение в приложении;
- D1-схема, Cron-обработчик, проверка webhook-секрета и AES-GCM для OAuth-токенов.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
pnpm install
pnpm run dev
```

Проверка:

```bash
pnpm run test
pnpm run lint
pnpm run build
pnpm run build:pages
```

## Публикация

GitHub Pages публикует статическую локальную версию из `main`. Защищённый backend собирается как Cloudflare Worker/Sites с D1. Секреты задаются только в защищённых переменных среды; список ключей без значений находится в `.env.example`.

Публичная серверная версия: <https://zapiski-mobile-pwa.ev87st-2.chatgpt.site>. Статическая версия GitHub Pages обращается к этому же backend; CORS ограничен двумя утверждёнными адресами приложения.

Инструкции для сопровождающего: [архитектура](docs/ARCHITECTURE.md), [развёртывание](docs/DEPLOYMENT.md), [приватность](docs/PRIVACY.md).
