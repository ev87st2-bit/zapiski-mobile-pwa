# Записки

Личное мобильное PWA для быстрых заметок, идей и задач. Все записи хранятся только в локальном хранилище браузера.

## Возможности

- экран «Сегодня» с задачами, просроченными делами и идеями для повторного просмотра;
- заметки, идеи с автоматической датой возврата через 7 дней и задачи с датой/временем;
- просмотренная идея уходит с экрана «Сегодня», но её можно снова отложить на 7 дней;
- голосовой ввод через доступный браузерный API без хранения аудио;
- календарь, редактирование, подтверждаемое удаление и история выполненных задач;
- устанавливаемый PWA, офлайн-оболочка и уведомления в пределах возможностей браузера.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Перед публикацией:

```bash
npm run lint
npm run build
```

Статическая версия для GitHub Pages:

```bash
npm run build:pages
```

Публикация запускается автоматически из ветки `main` через GitHub Actions.

## Приватность и напоминания

Приложение не использует аккаунты, облако или серверное хранилище. Браузерные уведомления не гарантируют фоновый запуск локального приложения, особенно на iOS; актуальные сроки всегда доступны на экране «Сегодня».
